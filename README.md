# College Event Registration Application

## Objective
To develop a college event registration system using
Python, MySQL, Git and GitHub.

## Modules
1. Event Management
2. Student Registration
3. Registration Records

## Technologies Used
- Python
- MySQL
- Git
- GitHub

## Features
- View college events, dates and venues.
- Register students for events.
- View registration records.
- Prevent duplicate registrations for the same event.

## Version Control
Feature branches and pull requests are used to
integrate the application modules.
